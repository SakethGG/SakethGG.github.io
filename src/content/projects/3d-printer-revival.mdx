I found a scrapped FDM-based 3D printer lying around in my lab. It is a 2020 model of the Creality Ender 3. I did not find all the parts that originally came with the printer. Actually, it is in bad condition and was completely dismantled by someone. Maybe they tried fixing it but could not because of some issue. Let's figure out what the problem is and maybe try to fix it.

Printer Name: Creality Ender 3 V2 (YUVA 2)

The first thing I noticed was that the Z-axis stepper motor is missing. The wire management is a complete disaster. I completely disconnected all the wires from the motherboard so I could get a clear picture of what is happening, as this is my first time working on a 3D printer.

I plan on using a different stepper motor in place of the missing Z-axis motor.

![](/images/projects/3d-printer-revival/printer-05.jpg)

I did some research online, and there are a lot of components missing, not only the Z-axis motor. It is missing an extruder stepper motor, a screen to set the print, the aluminium extrusion that goes through the middle, and more. This is going to be a lot more work than I initially thought it would be. I organized all the wrecked parts and used off-the-shelf screws to put it back together as much as possible.
