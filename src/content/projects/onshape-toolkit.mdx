Built while working on actuator and mechanism design, where manually updating link lengths across
dozens of configurations wasn't sustainable. This toolkit treats an Onshape CAD model as a
programmable object: authenticate over HMAC-SHA256, traverse documents and Variable Studios, and
read or push type-aware variable updates (`LENGTH`, `ANGLE`, `NUMBER`) straight from Python — turning
a parametric sweep into a script instead of an afternoon of clicking.
